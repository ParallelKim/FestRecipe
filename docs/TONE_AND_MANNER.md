# FestRecipe 톤앤매너

사용자 대면 텍스트(UI·안내·오류·SEO)의 목소리 기준.  
제품 가치·MVP 경계는 [`PRODUCT.md`](./PRODUCT.md).

## 가치 (카피에 스며들 것)

예습 · 선택 · 계획 — 동료 관객이 **같이 준비하는** 말투.

- 친근하되 과장·감탄사 없음.
- 지시·공문 말투 없음 ("~하시기 바랍니다" 금지).
- 다음에 할 일이 한 문장 안에 있게.

| 상황 | 피함 | 선호 |
|------|------|------|
| 기능 | "본 서비스는 … 제공합니다." | "타임테이블을 배경화면으로 저장해요." |
| 빈 상태 | "데이터가 존재하지 않습니다." | "아직 담은 아티스트가 없어요." |
| 오류 | "요청을 처리할 수 없습니다." | "페스티벌을 찾을 수 없어요." |

## 문장 규칙

- **해요체** 기본. 합니다체·반말 명사형 금지. 상태만 "~중…" 허용.
- **버튼:** 동사 원형, 짧게, 마침표 없음 — "담기", "YouTube로 듣기".
- **제목:** 명사형 — "내 라인업", "배경화면 편집".
- **안내:** 한두 문장, 짧게. **빈 상태·오류:** 상태 + 다음 행동.
- 말줄임표는 `…` (U+2026). `...` 금지.
- 기술 은어 금지: DPR → "기기 화면에 맞춤", YouTube Music → **YouTube**.

## 용어

| 개념 | 표기 | 쓰지 않음 |
|------|------|-----------|
| ☆로 고른 목록 | **내 라인업** | 나만의 플레이리스트 |
| 대표곡 묶음 | **대표곡** | 예상 셋리스트, 레시피 |
| 담는 동작/상태 | **담기** / **담김** | 픽, 추가 |
| 듣는 동작 | **듣기** | 연속 재생(UI 라벨) |
| 배경 PNG | **배경화면** | — |
| 아티스트 열기 | **누르기** | 클릭(카피) |
| 하루 단위 | **날짜** | 요일(UI) |
