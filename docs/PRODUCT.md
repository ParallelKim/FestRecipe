# FestRecipe 제품 원칙

코드와 카피가 흔들릴 때 돌아가는 **불변에 가까운 기준**만 적는다.  
스택·파일 트리·세션 핸드오프·벤치마크 조사는 문서로 쌓지 않는다. 그건 코드와 `package.json`이 말한다.

## 한 줄

페스티벌 가기 전에 **예습(대표곡)** · **선택(타임테이블)** · **계획(내 라인업·배경화면)** 을 돕는 준비 도구.

음악 스트리밍 앱이 아니다. 짧게 들러 정보를 훑고 **듣기·담기**로 끝낸다.

## MVP 경계

| 한다 | 하지 않는다 |
|------|-------------|
| 라인업 단계(전체 / 일별 / 타임테이블)에 맞는 UI | 예상 셋리스트·풀캠 타임스탬프·앱 내 재생 |
| YouTube로 대표곡 핸드오프 | YouTube Music 전용 UI·OS 시스템 컬러 피커 |
| 내 라인업(☆) · 배경화면 PNG | 계정 동기화(추후) |

`lineupStage`는 **뷰 분기 데이터**로 유지한다. 공개 진행 바 UI는 두지 않는다.

## 대표곡

- **아티스트 단독:** 인기순 대략 10~20곡.
- **번들(날짜·페스티벌·내 라인업):** 티어별 소수 곡(3~5)만.
- 듣기 카피·링크는 **YouTube**로 통일.

## 배경화면

- PNG 기본: **배경색 + 타임테이블만** (워터마크·긴 설명 없음).
- 캡션(이름·날짜)은 **선택, 기본 OFF**. 짧은 이름(`shortName`) 우선.
- 화면에 보이는 타임테이블과 **같은 그리드**를 쓴다. 보내기 전용 레이아웃을 따로 만들지 않는다.
