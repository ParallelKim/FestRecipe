# SEO

검색·소셜 미리보기에서도 페이지마다 올바른 제목·설명·이미지가 나가야 한다.  
카피 톤은 [`TONE_AND_MANNER.md`](./TONE_AND_MANNER.md).

## 규칙

1. **홈과 페스티벌 URL은 서로 다른 OG·스키마**를 갖는다. (홈: 사이트, 페스티벌: 이벤트)
2. 페스티벌이 늘거나 줄면 **빌드가 사이트맵·크롤러용 HTML을 갱신**한다. `sitemap.xml`을 손으로 고치지 않는다.
3. OG 이미지는 페스티벌 포스터가 있으면 그걸 쓰고, 없으면 기본 이미지를 쓴다.
4. canonical·사이트 URL은 실제 배포 도메인과 맞춘다.
5. 아티스트 수는 타임테이블이면 **슬롯 기준**, 그 외 단계는 라인업 목록 기준으로 센다. 메타용 숫자와 UI가 어긋나지 않게 같은 규칙을 쓴다.
